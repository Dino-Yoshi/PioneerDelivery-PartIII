# C-02 — Original-index traceback and cleanup tests

- **Status:** ACCEPTED at G2 and G3 (integration)
- **Owner:** W4
- **Prerequisite:** C-01
- **Acceptance gate:** G2 then G3
- **Design authority:** `../00_REQUIREMENTS_TRACEABILITY.md` and applicable detailed spec, plus original professor PDF.

## Scope

Recover one optimal ascending list of original eligible indices, and verify kept source preserves pattern.

## Acceptance criteria

1. Traceback from F[n][m], choose valid skip on equal-score tie, otherwise match transition.
2. Record source positions i-1 only when skipped and eligible, reverse to ascending original indices.
3. Result count equals DP optimum, indices unique/in-bounds/eligible.
4. Removing exactly listed original positions leaves pattern as subsequence; zero optimum means empty list.
5. Repeated-character/multiple-alignment and no/all-removal cases covered with actual tests.

## Evidence required

- traceback + kept-string verification
- named C test results
- original-index edge test
- readable scoped diff

## Out of scope

No mutation of source while computing shifting positions, no changes to other algorithm modules.

## Handoff / completion contract

Report changed paths, current branch/worktree, actual commands and exit statuses, concrete failures, tests/fixtures, blocker decisions, and session/checkpoint reference. No worker may commit/merge/push; orchestrator reviews all changes before acceptance.
