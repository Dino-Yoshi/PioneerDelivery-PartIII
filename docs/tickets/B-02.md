# B-02 — Knapsack reconstruction and regression tests

- **Status:** ACCEPTED at G2 and G3 (integration)
- **Owner:** W3
- **Prerequisite:** B-01
- **Acceptance gate:** G2 then G3
- **Design authority:** `../00_REQUIREMENTS_TRACEABILITY.md` and applicable detailed spec, plus original professor PDF.

## Scope

Trace the 2D table to output chosen unique delivery IDs, actual total fuel and total profit in input order.

## Acceptance criteria

1. If K[i][b]==K[i-1][b], exclude i; otherwise include and decrement budget before row move.
2. Each ID occurs at most once; total fuel <= B; sum(profits)==K[n][B].
3. Records empty/no-fit/zero-budget, exact-fit, ratio-greedy counterexample and equal-profit ties.
4. Official example and >=3 additional runnable cases produce actual test evidence.

## Evidence required

- reconstruction invariant tests
- named B results
- CTest logs
- scope diff

## Out of scope

No additional objective or external test framework.

## Handoff / completion contract

Report changed paths, current branch/worktree, actual commands and exit statuses, concrete failures, tests/fixtures, blocker decisions, and session/checkpoint reference. No worker may commit/merge/push; orchestrator reviews all changes before acceptance.
