# UX-01 — Five-minute first-run packaging and usability verification

- **Status:** ACCEPTED at G5-U (see docs/gates/G5-U.md)
- **Owner:** W1 + W5
- **Prerequisite:** G4
- **Acceptance gate:** G5-U
- **Design authority:** `../00_REQUIREMENTS_TRACEABILITY.md` and applicable detailed spec, plus original professor PDF.

## Scope

Produce tested Linux prebuilt quick-start distribution and have W5 independently measure the cold-start user journey from obtaining the archive to interpreting all three outputs.

## Acceptance criteria

1. Prebuilt archive works on an explicitly tested Linux architecture/distribution without compiler, CMake, Kiro, Claude Code or elevated privileges.
2. Root/subcommand help and concise README enable executing all three examples with no outside tutorial.
3. W5 records actual start/end time, platform, archive hash, friction and results; <=300 seconds goal measured (not guessed).
4. If packaging fails, fix it or narrow support statement; source ZIP still builds from documented commands.

## Evidence required

- Linux platform/version
- binary and archive manifests
- measured timed-run log
- user-style walkthrough feedback

## Out of scope

No unsupported cross-platform promises; no runtime agent/container dependence.

## Handoff / completion contract

Report changed paths, current branch/worktree, actual commands and exit statuses, concrete failures, tests/fixtures, blocker decisions, and session/checkpoint reference. No worker may commit/merge/push; orchestrator reviews all changes before acceptance.
