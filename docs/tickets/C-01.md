# C-01 — 2D subsequence/deletion DP

- **Status:** ACCEPTED at G2 and G3 (integration)
- **Owner:** W4
- **Prerequisite:** CORE-01
- **Acceptance gate:** G2
- **Design authority:** `../00_REQUIREMENTS_TRACEABILITY.md` and applicable detailed spec, plus original professor PDF.

## Scope

Implement 2D prefix DP maximizing deletions from eligible original source indices while matching the entire pattern as a subsequence.

## Acceptance criteria

1. State F[i][j] correctly counts best deletions for first i source characters and matched first j pattern chars.
2. Unreachable initial states explicitly represented and never combined as valid scores.
3. Skip transition earns one only for eligible original index, otherwise zero; match transition only on equal chars and advances pattern.
4. Bottom-up O(nm) time and O(nm) auxiliary space; size checked before allocation.
5. All four PDF example optima 1,2,0,2 and greedy-alignment adversarial optimum 3.
6. Ineligible skipped characters stay in source; no incorrect index shifting.

## Evidence required

- DP state/transition review
- four PDF example outputs
- unreachable state tests
- complexity rationale

## Out of scope

Original-index output traceback belongs to C-02; do not substitute a greedy or subset-search production algorithm.
