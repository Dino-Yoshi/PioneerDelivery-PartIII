- **Status:** NOT STARTED

- **Prerequisite:** A-01
- **Acceptance gate:** G2 then G3
- **Design authority:** `../00_REQUIREMENTS_TRACEABILITY.md` and applicable detailed spec, plus original professor PDF.

## Scope

Reconstruct one optimal chronological nonoverlapping schedule, implement deterministic exclude-on-tie policy, and complete specified named regression tests.

## Acceptance criteria

1. On inclusion, traceback jumps to p(i); on tie, excludes current item.
2. Selected IDs are in chronological order and unique; intervals never overlap; total cents equals DP[n].
3. Handles n=0, zero profit, equal finishes, shuffled input and touching endpoints.
4. Greedy counterexample is covered, as are actual tests for PDF example and >=3 more cases.
5. Supports independent W5 oracle checking without sharing production DP code.

## Evidence required

- traceback invariant tests
- named A test outputs
- change summary and test logs

## Out of scope

No arbitrary minimum-delivery secondary objective and no changes to unrelated modules.

## Handoff / completion contract

Report changed paths, current branch/worktree, actual commands and exit statuses, concrete failures, tests/fixtures, blocker decisions, and session/checkpoint reference. No worker may commit/merge/push; orchestrator reviews all changes before acceptance.
