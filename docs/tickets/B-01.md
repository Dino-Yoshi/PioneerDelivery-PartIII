# B-01 — 2D knapsack DP

- **Status:** ACCEPTED at G2 and G3 (integration)
- **Owner:** W3
- **Prerequisite:** CORE-01
- **Acceptance gate:** G2
- **Design authority:** `../00_REQUIREMENTS_TRACEABILITY.md` and applicable detailed spec, plus original professor PDF.

## Scope

Implement the professor-mandated two-dimensional bottom-up DP for maximum profit under nonnegative budget with positive per-delivery fuel costs.

## Acceptance criteria

1. State K[i][b] means first i items at most budget b.
2. Both transitions reference row i-1; cannot reuse current delivery.
3. Empty set and zero budget return zero.
4. Official example optimum 53, exact fit and too-expensive items handled.
5. Checks dimensions/allocation and profit addition overflow, rejects unmanageable tables instead of switching to 1D.
6. Time/space O(nB); no secondary minimize-fuel optimization.

## Evidence required

- DP base/transition unit tests
- official output and edge cases
- safe allocation rejection test
- complexity note

## Out of scope

Item reconstruction belongs to B-02; no greedy production solution.
