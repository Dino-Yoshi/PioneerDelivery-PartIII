## Scope

Implement Task A sorted-by-finish preprocessing, binary-search p(i), and bottom-up weighted interval DP in a focused module.

## Acceptance criteria

1. Sorted finish order with retained IDs and deterministic secondary order.
2. p(i) finds last earlier finish <= current start using binary search; no search beyond prefix i-1.
3. DP[0]=0, DP[i]=max(DP[i-1],profit_i+DP[p(i)]) with cents arithmetic overflow checks.
4. Correct official optimum 180.00, empty input, overlapping and endpoint-touching cases.
5. O(n log n) overall target and O(n) DP/predecessor storage (sorting storage excluded).
6. Code is readable; no greedy or exhaustive production search.
